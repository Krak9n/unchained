OpenGL implementation of [Conway's Game of Life](https://en.wikipedia.org/wiki/Conway%27s_Game_of_Life). I was working on this cpp based game engine last year. Plan on finishing it in close time. 

This will be a Game of Life in it's active environment. To start evaluation you'd press <SPACE>, same goes for stopping. During both processes you could interact with the grid by pressing the mouse wherever you want.

### Dependencies
* **cmake** >= 3.23
* **freetype2**
* **glfw3** 

### Building
```bash
$ cmake -B build
$ cmake --build build
```
